# Domain Articles Layer

Папка `src/domain/articles/` содержит типы, загрузчики и логику для статей блога:
- Специфичные типы для статей (`articles.types.ts`).
- Загрузчик статей (`articles.loader.ts`), обрабатывающий переводы и метаданные.
- Хуки для доступа к списку статей и отдельным записям (`useArticles.ts`).
