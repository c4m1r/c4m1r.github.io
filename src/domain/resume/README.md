# Domain Resume Layer

Папка `src/domain/resume/` объединяет данные и логику резюме (CV):
- Описание типов профиля резюме, опыта работы, навыков и образования (`resume.types.ts`).
- Единый загрузчик данных резюме из общего JSON/Markdown источника (`resume.loader.ts`).
- React-хуки для доступа к данным резюме на сайте-визитке и в Desktop-приложении (`useResume.ts`).
