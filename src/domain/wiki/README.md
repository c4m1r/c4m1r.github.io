# Domain Wiki Layer

Папка `src/domain/wiki/` отвечает за структуру и загрузку страниц базы знаний (Wiki):
- Типы категорий и страниц wiki (`wiki.types.ts`).
- Функции парсинга иерархических категорий и статей (`wiki.loader.ts`).
- Хуки для получения дерева категорий и поиска по wiki (`useWiki.ts`).
