# Windows 2000 Start menu icons (16 px)

Native Windows 2000 shell bitmaps used by the classic Start menu.

Top-level rows use the 32 px bitmaps (`*-32.png`), taken from `eat/windows2000-main/src/assets/ICON` ids 104, 110, 116, 122, 128, 134 and 139.

Still missing from the Windows 2000 set: Calculator, Outlook Express and Minesweeper. They keep Windows 98 artwork until native bitmaps are added.
