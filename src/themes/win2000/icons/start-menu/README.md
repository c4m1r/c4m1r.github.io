# Windows 2000 Start menu icons (16 px)

- `programs-16.png`, `accessories-16.png`, `documents-16.png`, `settings-16.png`, `find-16.png`, `help-16.png`, `run-16.png`, `shutdown-16.png`, `update-16.png`, `internet-explorer-16.png`: downscaled from the native Windows 2000 ICO set in `eat/windows2000-main/src/assets/ICON/` (LANCZOS, no upscaling).
- `notepad-16.png`, `paint-16.png`: native 16 px bitmaps `w2k_notepad_1` and `w2k_paint_2` from `Source Icons/w2k` in https://github.com/matthewmx86/WinClassic_icons (no SVG is published for these roles in that repo).
- `media-player-16.png`: native 16 px bitmap `w2k_mplayer32_1` from the same source. This is the Media Player application icon as identified by eye; confirm against a period screenshot.

Still missing in the Windows 2000 set: Calculator, Outlook Express, Minesweeper. They keep Windows 98 artwork until an authentic source is found.
