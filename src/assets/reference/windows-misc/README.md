# Windows wallpapers and icons (reference)

Nothing here is imported by the app yet. The files are kept so the detailed skins can be built 1 to 1 later.

- `win11-wallpapers/` — 18 wallpapers from the Windows 11 pack (`windows-11-wallpapers.zip`). `win11-img0.jpg` (3840×2400) is the default "Bloom" wallpaper and is already wired in `src/themes/win11/assets/wallpaper.jpg`; the rest are reference only.
- `win8-wallpapers/win8-daisy.jpg` — Windows 8 default wallpaper (1280×800, file name `Img0_Windows_8.jpg`). Waits for a Windows 8 skin root class.
- `server2003-wallpapers/server2003-clean.png` — clean Windows Server 2003 wallpaper (800×600). Waits for the server2003 profile to get its own wallpaper (it currently uses the Windows XP theme).
- `win81-flat-icons/` — Windows 8.1 "Flat Colors" icon pack: 84 ICO files plus the `.iconpackage` manifest (from `Windows 8.1 Flat Colors.rar`). Not mapped to any shell element yet.

Licence: no licence files were supplied with these packs. Source and provenance are recorded in `docs/external-references.md`.
