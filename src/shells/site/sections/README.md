# Site Shell Sections

Папка `src/shells/site/sections/` содержит визуальные компоненты секций сайта-визитки:
- `HomeSection.tsx` — главный экран приветствия.
- `AboutSection.tsx` — раздел биографии.
- `NewsSection.tsx` — раздел новостей.
- `ArticlesSection.tsx` — блог / статьи.
- `WikiSection.tsx` — база знаний.
- `ProjectsSection.tsx` — сетка проектов.
- `ResumeSection.tsx` — секция с резюме/CV.
