# Site Shell

Папка `src/shells/site/` содержит реализацию основного сайта-визитки (Portfolio Website):
- `SiteShell.tsx` — корневой контейнер сайта-визитки, управляющий структурой страницы, шапкой, подвалом и боковыми панелями.
- `routes.ts` — маршруты и разделы сайта.
- `sections/` — отдельные визуальные секции сайта.
