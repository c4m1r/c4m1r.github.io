# Desktop Shell

Папка `src/shells/desktop/` содержит реализацию графической среды Desktop OS:
- `DesktopShell.tsx` — корень рабочего стола, управляющий таскбаром, меню Пуск, иконками рабочего стола и инициализацией.
- `DesktopWindow.tsx` — компонент хрома окна (кнопки закрытия/сворачивания, drag-and-drop, resize).
- `appRegistry.tsx` — реестр доступных для запуска приложений и сопоставление их `appId` с React-компонентами.
- `shortcutsRegistry.ts` — реестр ярлыков рабочего стола и меню Пуск.
- `apps/` — папка со встроенными приложениями.
