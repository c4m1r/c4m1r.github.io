# Desktop Resume App

Папка `src/shells/desktop/apps/resume/` содержит приложение для просмотра резюме разработчика внутри Desktop OS:
- `ResumeApp.tsx` — точка входа, отображающая резюме в виде интерактивного документа.
- Использует доменный загрузчик `useResume` для получения актуального профиля.
- Стилизуется с помощью общих классов `os-button`, `os-panel`, а визуальный скин (XP, 7, Ubuntu) накладывается через тему рабочей среды.
