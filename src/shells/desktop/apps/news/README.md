# Desktop News App

Папка `src/shells/desktop/apps/news/` содержит реализацию приложения новостей для Desktop OS:
- `NewsApp.tsx` — точка входа в приложение, объединяющая боковую панель списка и окно чтения статьи.
- `NewsListPane.tsx` — левая панель со списком новостей и фильтрами по дате/категориям.
- `NewsReaderPane.tsx` — правая панель для чтения выбранного материала с рендерингом Markdown.
