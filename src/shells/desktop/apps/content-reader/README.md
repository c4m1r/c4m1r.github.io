# Desktop Content Reader App

Папка `src/shells/desktop/apps/content-reader/` содержит универсальный просмотрщик контента:
- `ContentReaderApp.tsx` — приложение-заглушка/просмотрщик, умеющее отображать любой `BaseContentItem` (статью блога, проект, вики-страницу) по его ID.
- Автоматически выбирает нужный рендерер в зависимости от типа контента (`ContentKind`).
- Используется как резервное (fallback) приложение для открытия текстовых файлов/ссылок с рабочего стола.
