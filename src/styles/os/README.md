# OS Styles Layer

Папка `src/styles/os/` содержит ядро CSS-оболочки для тем оформления различных операционных систем:
- `index.css` — точка входа, импортирующая токены и конкретные темы.
- `tokens.css` — базовые CSS-переменные (цвета, шрифты, отступы, тени).
- `os-base.css` — сброс стилей и общие классы для каркаса оконной среды (`os-shell`, `os-window`, `os-button`, `os-titlebar` и т.д.).
- `classic.css` — оформление в стиле классической Windows 95/98.
- `winxp.css` — тема оформления Windows XP (Luna).
- `win7.css` — тема оформления Windows 7 (Aero).
- `ubuntu.css` — тема оформления Ubuntu (Ambiance/Yaru).
