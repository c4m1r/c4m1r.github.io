# Windows 8.1

Каталог редакций подготовлен для будущего Windows 8.1-профиля WebOS. Пока отдельной реализованной среды Windows 8.1 в GRUB нет.

## Windows 8.1

Базовая редакция - развитие Windows 8 с доработанным интерфейсом и возвращенной кнопкой Пуск.

## Windows 8.1 Pro

Профессиональная редакция с присоединением к домену, BitLocker, Hyper-V и удаленным рабочим столом.

## Windows 8.1 Enterprise

Корпоративная редакция с расширенными сетевыми и административными возможностями.

## Windows RT 8.1

Обновление ARM-ветки Windows RT для соответствующих планшетов и специализированных устройств.

## Windows 8.1 with Bing

OEM-вариант для недорогих устройств с Bing в качестве поиска по умолчанию.
