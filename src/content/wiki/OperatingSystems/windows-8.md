# Windows 8

Каталог редакций подготовлен как задел для будущего Windows 8-профиля WebOS. Пока Windows 8 не добавлена как отдельная полноценно реализованная среда GRUB, поэтому выбор этих редакций не создает фиктивный загрузочный пункт.

## Windows 8 - Core

Базовая версия для домашних компьютеров и обычных ноутбуков. Она заменила прежнее разделение домашних редакций на Home Basic и Home Premium.

## Windows 8 Pro

Профессиональная версия с BitLocker, Hyper-V, присоединением к домену и возможностями удаленного рабочего стола.

## Windows 8 Enterprise

Корпоративная редакция с DirectAccess, BranchCache и дополнительными средствами централизованного управления.

## Windows RT

Редакция для ARM-процессоров. Обычные настольные Win32-программы на ней не устанавливались; основной канал приложений - Windows Store. Наиболее известные устройства этого семейства - ранние Surface RT.

## N / Pro N / Enterprise N

Европейские варианты соответствующих редакций без Windows Media Player и части мультимедийных компонентов.

## Single Language

OEM-редакция с ограничением на один язык интерфейса. Часто поставлялась на недорогих ноутбуках для конкретного рынка.

## with Bing

OEM-вариант для недорогих устройств, в котором производитель должен был сохранять Bing поиском по умолчанию.
