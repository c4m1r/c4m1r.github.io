# Windows 7

В WebOS Windows 7 использует отдельную Aero-среду, экран выбора пользователя, post-login **Welcome**, Superbar и собственный Explorer. В GRUB пункт помечен `*`: клавиша **E** открывает выбор редакции.

## Начальная - Starter

Редакция для самых бюджетных ПК и нетбуков. Сильно ограничена по сравнению со старшими выпусками: только 32-битная система, до 2 ГБ памяти и без полного Aero Glass.

## Домашняя базовая - Home Basic

Недорогая домашняя редакция для отдельных рынков. По возможностям интерфейса и мультимедиа проще Home Premium.

## Домашняя расширенная - Home Premium

Классическая домашняя Windows 7 с Aero Glass, расширенными мультимедийными возможностями и Windows Media Center.

## Профессиональная - Professional

Рабочая редакция с присоединением к домену, EFS и Windows XP Mode для запуска несовместимого старого ПО.

## Корпоративная - Enterprise

Редакция для крупных организаций. Включает BitLocker, AppLocker, корпоративные сетевые функции и сценарии массового лицензирования.

## Максимальная - Ultimate

Розничная максимально полная редакция Windows 7. Объединяет домашние и корпоративные возможности, BitLocker и языковые пакеты.

## Windows Embedded Standard 2011 - Quebec

Модульная Windows на технологиях Windows 7. Производители банкоматов, медицинского оборудования, терминалов и других специализированных устройств могли собирать необходимый набор компонентов.

## Windows Embedded Compact 7 - CE7

Отдельная компактная система семейства Windows Embedded для тонких клиентов и специализированных устройств. Это не просто урезанная настольная Windows 7.

## Windows Embedded POSReady 7

Специализированная система для POS-терминалов, касс, киосков самообслуживания и другого оборудования розницы/сервиса. Основана на технологиях Windows 7 Professional SP1.

В текущей эмуляции выбор редакции меняет прежде всего подпись `Windows 7 <Edition> *` в GRUB и соответствующую надпись на экране приветствия. Функциональные различия редакций оставлены как задел следующего этапа.
