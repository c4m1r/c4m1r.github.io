# Операционные системы WebOS

Эта категория используется приложением **«Справка о WebOS»** и описывает среды, доступные из GRUB-подобного загрузчика проекта.

## Реализованные пункты загрузчика

- Windows 98
- Windows XP
- Windows 7
- Windows 10
- Windows 11
- Ubuntu
- iOS 6
- iOS
- Arch Linux
- Halloween OS
- WebOS
- Blog Site
- Terminal

Редакции одной и той же Windows не создаются как отдельные основные пункты GRUB. Если у системы есть поддерживаемые ревизии, рядом с названием показывается `*`, а клавиша **E** открывает экран выбора редакции.

На текущем этапе редакция влияет на подпись системы и брендинг экранов входа/приветствия. Отличия наборов программ и возможностей будут подключаться на заключительном этапе полировки проекта.
