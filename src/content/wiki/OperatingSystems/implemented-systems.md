# Реализованные системы WebOS

Ниже перечислены среды, которые реально доступны в текущем GRUB WebOS. Это основные профили загрузки; редакции Windows считаются вариантами одного профиля и не занимают отдельные строки GRUB.

## Windows XP

Среда Windows XP с Luna-интерфейсом, классическим экраном выбора пользователя, отдельным синим экраном приветствия после входа, XP Explorer, системными приложениями и панелью задач.

## Windows 98

Классическая Windows-среда проекта: серые системные элементы, старое меню Пуск, оконный интерфейс семейства Windows 9x и отдельная последовательность входа. XP-экран `Welcome` к Windows 98 не относится.

## Windows 7

Среда Windows 7 с Aero, Superbar, отдельным Explorer, экраном выбора пользователя и post-login Welcome. Поддерживает выбор редакции через `E` в GRUB.

## Ubuntu

Linux-профиль Ubuntu с отдельной визуальной темой поверх общей среды приложений WebOS.

## Arch Linux

Linux-профиль Arch с собственной стилизацией и общими приложениями WebOS.

## iOS 26.6.1

Современный мобильный профиль iOS 26.6.1.

## iOS 16.7.16

Профиль iOS 16.7.16 для предыдущего поколения мобильной оболочки.

## iOS 9.3.6

Ретро-профиль iOS 9.3.6.

## iOS 5.1.1

Ретро-профиль iOS 5.1.1.

## Halloween Edition

Тематическая экспериментальная оболочка WebOS, сохраняющая общий runtime приложений.

## WebOS

Базовая авторская оболочка проекта, объединяющая приложения, Wiki, проекты и системные поверхности.

## Мой сайт / Blog Site

Прямой переход из GRUB к сайту/блогу без загрузки эмулируемого рабочего стола.

## Терминал / Terminal

Прямой переход из GRUB в терминальный режим проекта.

## Поведение завершения сеанса

- **Выключение компьютера / Shut down** завершает текущую оболочку и возвращает в GRUB.
- **Завершение сеанса / Log off** возвращает к экрану выбора пользователей текущей операционной системы.
