# Non-original sound files

Files here are not original Windows system sounds. They are kept out of the app and can be cut out for other projects.

- `windows-7-startup.mp3`: previous Windows 7 startup sound. Replaced by the original `Startup.wav` from the Windows 7 default scheme.
- `windows-98-startup.mp3`: previous Windows 98 startup sound. Replaced by the original `Windows 98 startup.wav`.
